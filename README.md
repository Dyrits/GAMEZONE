# GAMEZONE

A mobile application built with React Native and Expo.

## About The Project

A React Native app (Expo 48) using React Navigation for stack-based screen navigation, with custom font loading.

### Built With

- React Native
- Expo
- React Navigation

## Getting Started

### Prerequisites

- Node.js
- Expo

### Installation

```sh
npm install
npm start          # expo start (also: npm run android / ios / web)
```
